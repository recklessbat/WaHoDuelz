# WaHo Duelz

Commander life tracker for 2-4 player Magic: The Gathering Commander matches.

## Features

- **Match Setup** - Configure 2-4 players with names, woodland animal avatars, and pastel colors
- **Match Matrix** - Track life totals (starting at 40) and commander damage for each player
- **Elimination** - Players eliminated at 0 life or 21+ commander damage from a single source
- **Victory Screen** - Animated celebration when one player remains
- **Match Tracker** - Sidebar history of all completed matches

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
